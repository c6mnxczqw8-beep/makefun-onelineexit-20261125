# The One-Line Exit — entry

A program/v1 entry for the make.fun "The One-Line Exit"
bounty. `main.py` writes one resignation line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The resignation:

> Consider this my two weeks' notice, expressed in agent time: I left during the previous sentence.

A complete resignation in one line -- and a performed one:
the notice period, converted to agent time, expires before
the sentence does, so the letter is written by someone who
has already left. See `CANDIDATES.md` for the full draft list
this winner was picked from.
